# Folder Foto Profil

Folder ini disiapkan khusus untuk menyimpan foto profil portofolio Anda.

## Cara Mengganti Foto Profil:
1. Siapkan file foto profil Anda (disarankan berformat persegi / rasio 1:1, misalnya 600x600 atau 800x800 px).
2. Simpan file foto Anda di folder ini (`public/images/`) dengan nama file:
   - `profile.jpg` atau `profile.png`
3. Komponen Hero di `src/components/Hero.tsx` siap menampilkan foto Anda secara otomatis.
